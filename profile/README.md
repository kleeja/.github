Kleeja is a PHP file upload and sharing platform you host yourself. It runs on almost any shared hosting.

- **File control:** per-extension rules, with separate size limits for guests and members
- **Images:** automatic thumbnails and watermarks
- **Accounts:** built-in users, or integration with phpBB and vBulletin
- **Protection:** captcha, flood control, abuse reports, and deletion links
- **Extensible:** multi-language, with plugins and styles

### Get started

1. Download the [latest release](https://github.com/kleeja/kleeja/releases).
2. Follow the [installation guide](https://kleeja.net/getting-started/installation).
3. Customize with [plugins](https://kleeja.net/guides/install-plugins) and [styles](https://kleeja.net/guides/install-styles).

### Contribute

Bug reports, translations, and pull requests are welcome in [kleeja/kleeja](https://github.com/kleeja/kleeja). If you want to build extensions, read the [plugin](https://kleeja.net/development/plugin-development) and [style](https://kleeja.net/development/styles-development) development guides.
